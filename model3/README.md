# Калькулятор 3 — бестрансплантационная выживаемость

## Формула

```text
hi(t) = h0(t) * exp(0.007 * X_ОБ + 0.005 * X_АЛТ-2 - 0.614 * X_T) * 100%
```

где:

- `X_ОБ` — уровень общего билирубина крови, мкмоль/л;
- `X_АЛТ-2` — уровень аланинаминотрансферазы в первые 6 месяцев после
  завершения терапии, Ед/л;
- `X_T` — тактика лечения и профилактики:
  - 1 — эндоскопическая;
  - 2 — комбинированная малоинвазивная хирургическая.

Пороговое значение (cut-off): **74.5%**.

Отображаемое значение ограничивается сверху 100%. Например, расчётные 471.40%
выводятся как `100.00%`.

## Базовый риск h0(t)

Значения взяты из таблицы 30. `h0(t)` — коэффициент базового риска,
поэтому в формуле он умножается на 100%.

| Период наблюдения     | h0(t) |
| --------------------- | ----: |
| до 1 года (6–12 мес.) | 0.113 |
| 1 год                 | 0.319 |
| 2 года                | 0.571 |
| 3 года                | 0.672 |
| 4 года                | 0.910 |
| 5 лет                 | 1.309 |
| 6 лет                 | 1.584 |
| 7 лет                 | 2.524 |
| 9 лет                 | 3.054 |
| 10 лет                | 3.723 |

## Проверочные примеры

Для 4 лет, билирубина 30 мкмоль/л и АЛТ 40 Ед/л:

|             Тактика | hi(t), % | Отображение |
| ------------------: | -------: | ----------: |
| 1 — эндоскопическая |    74.21 |      74.21% |
| 2 — комбинированная |    40.16 |      40.16% |

Для 10 лет, билирубина 50 мкмоль/л, АЛТ 100 Ед/л и тактики 1 расчётное
значение 471.40% отображается как `100.00%`.
