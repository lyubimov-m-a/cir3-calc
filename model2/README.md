# Калькулятор 2 — безрецидивная выживаемость

## Формула

```text
hi(t) = h0(t) * exp(0.009 * X_П-ВРВП
                    + 0.651 * X_N-ВРВЖ
                    - 1.702 * X_T-ВРВЖ
                    - 1.03 * X_T) * 100%
```

где:

- `X_П-ВРВП` — максимальная протяжённость варикозно расширенных вен пищевода, мм;
- `X_N-ВРВЖ` — количество варикозно расширенных вен желудка;
- `X_T-ВРВЖ` — тип варикозного расширения вен желудка по Sarin:
  - 0 — нет ВРВЖ;
  - 1 — GOV1;
  - 2 — GOV2;
  - 3 — IGV1;
  - 4 — IGV2;
- `X_T` — тактика лечения и профилактики:
  - 1 — эндоскопическая;
  - 2 — комбинированная малоинвазивная хирургическая.

Пороговое значение (cut-off): **88.8%**.

Отображаемое значение ограничивается сверху 100%. Например, расчётные 128.62%
выводятся как `100.00%`.

## Базовый риск h0(t)

Значения взяты из таблицы 25. `h0(t)` — коэффициент базового риска,
поэтому в формуле он умножается на 100%.

| Период наблюдения | h0(t) |
| ----------------- | ----: |
| 1 год             | 0.130 |
| 2 года            | 0.336 |
| 3 года            | 0.582 |
| 4 года            | 0.672 |
| 5 лет             | 1.064 |
| 6 лет             | 1.546 |
| 10 лет            | 2.172 |
| 11 лет            | 3.187 |

## Проверочные примеры

Для 3 лет, протяжённости ВРВП 30 мм и тактики 1:

| Тип Sarin | Количество ВРВЖ | hi(t), % | Отображение |
| --------: | --------------: | -------: | ----------: |
|         1 |               0 |     4.96 |       4.96% |
|         2 |               0 |     0.90 |       0.90% |
|         1 |               3 |    34.98 |      34.98% |
|         1 |               4 |    67.08 |      67.08% |
|         1 |               5 |   128.62 |     100.00% |
