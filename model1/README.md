# Калькулятор 1 — летальность до 6 месяцев

Приложение на Python + PyQt6 для расчёта вероятности летального исхода в первые
6 месяцев после минимально инвазивного хирургического лечения и профилактики
портальных кровотечений у больных циррозом печени.

## Формула

```text
z = -14.6 + 3.3 * Xпоказ-я + 0.53 * XПК
P = 1 / (1 + exp(-z)) * 100%
```

где:

- `Xпоказ-я` — вид показаний к малоинвазивной хирургической коррекции:
  - 0 — нет показаний;
  - 1 — первичная профилактика;
  - 2 — вторичная профилактика;
  - 3 — лечение состоявшегося кровотечения;
  - 4 — лечение продолжающегося кровотечения;
- `XПК` — число портальных кровотечений в анамнезе.

Пороговое значение (cut-off): **2.04%**. При `P >= 2.04%` результат
выводится красным.

## Проверочные примеры

| Xпоказ-я |  XПК |   P, % |
| -------: | ---: | -----: |
|        0 |    0 | ≈ 0.00 |
|        3 |    1 |   1.52 |
|        3 |    2 |   2.56 |
|        4 |    0 |  19.78 |
